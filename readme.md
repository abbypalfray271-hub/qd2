# 中考语文 专属知识库 (Middle School Chinese Subject Knowledge Base)

## 📌 1. 项目愿景 (Overview)
本知识库为 **【E:\中考库】** 旗下的**中考语文专属子知识库**。
秉持**结构清晰、精准攻坚、融会贯通**的原则，全面归纳中考语文核心考法与知识网络：
- **基础知识与运用**（字音字形、词语成语、病句辨析、修辞手法、标点符号、语言表达）
- **古诗文阅读与积累**（名句名篇默写、文言实词虚词、诗歌鉴赏、文言文对比阅读）
- **现代文阅读**（记叙文/散文阅读、说明文阅读、议论文阅读、文学类文本赏析）
- **名著导读与综合性学习**（部编版必读名著、综合性学习、图表信息提取）
- **写作与表达**（命题作文、半命题作文、审题立意、素材积累与结构提纯）

---

## 📁 2. 文件夹权限与物理法则 (Directory Rules)
本子库严格遵守四分法目录结构与读写权限：

- 📂 **`raw/`**：**原始素材库（只读）**。存放中考语文专属原始试卷、WORD/PDF 真题汇编、网络下载考题等未加工素材。**【系统指令】：AI 永远不要修改此文件夹中的任何文件。**
- 📂 **`wiki/`**：**维基知识库（AI 专属领地）**。存放结构化的语文知识卡片和考点词条。该目录完全由 AI 分析、归纳、维护与迭代。
- 📂 **`outputs/`**：**输出物**。用于存放基于本知识库生成的二次加工内容，如中考语文专项突破讲义、冲刺复习卷、错题分析报告等。
- 📂 **`skills/`**：**工程规约与技能库**。存放知识获取、清洗规范、结构化提纯 SOP 及自动化转换脚本。

---

## 📝 3. 维基整理与维护规则 (Wiki Maintenance Rules)
当 AI 处理 `raw/` 中的新素材并将其转化为 `wiki/` 或 `outputs/` 内容时，必须严格遵守以下法则：

1. **时间戳命名法 (Timestamped Naming)**：所有 AI 生成的文件名称必须带有时间标记：`YYYYMMDD_主题名称.md`（例：`20260819_文言文高频实词.md`）。
2. **一题一文 (Atomic Notes)**：每个独立的核心考点、语法规则或名著词条，只能建立一个对应的 `.md` 文件。
3. **摘要先行 (Summary First)**：正文开头必须包含一段简明扼要的“摘要”，高度概括核心考法与答题技巧。
4. **双向链接 (Bi-directional Links)**：强制使用 `[[主题名称]]` 构建互相关联的中考语文知识图谱。
5. **动态索引 (Dynamic Index)**：在 `wiki/` 目录下维护全局 `20260819_INDEX.md` 索引文件。

## 🤖 4. AI 协作与工作流指导 (AI Workflow)
- **沟通语言**：永远使用**简体中文**进行交互与文档写作。
- **操作协议**：遵循“先诊断/分析 -> 提出构建方案 -> 等待确认 (Yes) -> 执行落地”的协作模式。
