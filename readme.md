# 青岛中考语文 全要素题库与教研组卷系统 (Qingdao Chinese Exam System)

## 📌 项目概述
本项目已从旧中考库中完全独立剥离，成为顶级独立专属工程 **【E:\青岛中考语文】**。
完整归档了青岛中考语文全量真题与最新区县模拟题数据（共计 **51 套** 高清结构化试卷，2018～2026年）、React 19 + TypeScript + Vite 前端在线教研平台、Express + docx 后端高保真 A4 Word/PDF 排版导出引擎及全自动构建流水线。

---

`

## 🚀 启动与使用方式

### 方式一：一键双击启动（推荐）
直接在资源管理器双击运行 **启动全套服务.bat**：
- 后端导出服务自动在 http://localhost:3001 启动
- 前端 Web 平台自动在 http://localhost:5173 启动
- 浏览器访问 http://localhost:5173/ 即可直接体验！

### 方式二：命令行手动启动
`ash
# 启动后端
cd /d E:\青岛中考语文\server
npm start

# 启动前端
cd /d E:\青岛中考语文\web-app
npm run dev
`
